# Hongo the Collector

Hongo the Collector est une petite application Flask pour gérer des fichiers et dossiers depuis une interface web simple.

## Fonctionnalités

- Créer un dossier
- Déplacer un fichier ou un dossier
- Rechercher dans un dossier
- Supprimer un fichier ou un dossier

## Prérequis

- Python 3
- Flask

## Installation

```bash
pip install -r requirements.txt
```

## Lancement

```bash
python app.py
```

Puis ouvrez :

```text
http://127.0.0.1:5000
```

## Remarques

Cette application fonctionne localement et manipule les chemins de fichiers du système.
